# ConectaAcessível — versão 2

Protótipo acadêmico de site educativo sobre inclusão digital para pessoas surdas.

## Como abrir
1. Baixe e extraia o arquivo ZIP.
2. Abra a pasta `ConectaAcessivel_v2`.
3. Dê dois cliques em `index.html`.
4. Use o menu para navegar entre as páginas internas.

Não é necessário acessar o GOV.br para navegar no conteúdo do protótipo. Os conteúdos principais estão dentro do próprio site.

## Estrutura
- `index.html`: página inicial
- `paginas/`: páginas internas sobre Libras, comunicação, ferramentas e aprendizagem digital
- `css/style.css`: estilos
- `js/script.js`: controles de tamanho do texto e alto contraste

## Tecnologias
HTML5, CSS3 e JavaScript puro.

## Limitações
É um protótipo educativo. Não oferece tradução automática de Libras, não substitui intérprete e ainda precisa ser testado com usuários. Aumentar fonte e contraste são recursos iniciais, não uma certificação de acessibilidade.


## Seção de vídeos acessíveis
A página `paginas/videos.html` apresenta três conteúdos audiovisuais planejados. Os vídeos ainda não estão incorporados; a página identifica isso explicitamente e descreve os critérios para futura publicação (Libras revisada, legendas e resumo textual). Não inserir vídeos sem verificar autoria, direitos de uso e qualidade linguística.
